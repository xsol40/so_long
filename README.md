## 🎮 About the Game

**so_long** is a 2D game where you navigate through a zombie-infested world inspired by The Walking Dead. Collect supplies, eliminate walkers, and find your way to the exit to survive.

## 🛠️ How to Compile
```bash
make bonus
./so_long_bonus ./maps/map1_bonus.ber
```

## 🕹️ How to Play

**Controls:**
- `W` - Move Up
- `A` - Move Left
- `S` - Move Down
- `D` - Move Right
- `SPACE` - Kill Enemies
- `ESC` - Exit Game

**Objective:**
Collect all items, eliminate the walkers, and reach the exit to win!
